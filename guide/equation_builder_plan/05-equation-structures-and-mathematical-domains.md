# 5. Equation Structures and Mathematical Domains

## 5.1 Core structures
- Fraction, continued fraction, binomial.
- Square/nth root.
- Superscript/subscript.
- Overline, underline, hat, tilde, vector accent.
- Parentheses, brackets, braces, scalable delimiters.
- Absolute value and norm.
- Text within mathematics.
- Cases and piecewise functions.
- Underbrace and overbrace.
- Cancel and boxed expressions.
- Stackrel, overset, underset.
- Multi-line aligned expressions.

## 5.2 Matrices and arrays
- Matrix, pmatrix, bmatrix, Bmatrix, vmatrix, Vmatrix.
- Smallmatrix.
- Array with column alignment.
- Augmented matrix and vertical/horizontal separators.
- Dynamic row/column addition and removal.
- Cell navigation and paste from spreadsheet-like data.
- Matrix transpose/inverse notation.
- Block matrix templates.
- Determinant.
- Sparse matrix layout.

## 5.3 Multi-line environments

- align / align*
- aligned
- gather / gather*
- gathered
- multline / multline*
- split
- flalign
- alignat
- cases
- array
- subequations

Features:
- Add/remove rows.
- Add alignment points.
- Set per-row numbering/tagging.
- Suppress numbering for selected rows.
- Add line spacing.
- Add equation labels.
- Choose left/center/right alignment where supported.
- Validate environment nesting.

## 5.9 Diagrams in mathematics
- Commutative diagrams using tikz-cd or CD environment in configured profiles.
- Tensor diagrams only as a later specialized module.
