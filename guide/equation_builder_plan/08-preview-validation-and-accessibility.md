# 8. Preview, Validation and Accessibility

## 8.1 Preview architecture
Use a preview adapter. Evaluate MathJax 4 for broad TeX-oriented browser rendering and MathML/accessibility output. KaTeX may be used for fast preview of a supported subset. The final PDF generated by TeX Live is authoritative.

Do not claim browser preview supports all LaTeX packages or macros.

## 8.2 Preview states
- Rendering.
- Valid.
- Partial/unsupported command.
- Parse error.
- Preview timeout.
- Macro undefined.
- Renderer limitation.
- Stale preview.

Clearly distinguish browser preview errors from TeX Live compilation errors.

## 8.3 Validation
Structural:
- unmatched braces
- unmatched delimiters
- unclosed environments
- mismatched environment names
- missing required arguments
- malformed matrix row/column syntax
- invalid alignment markers
- duplicate labels
- missing references
- empty required arguments
- malformed command arguments

Semantic warnings:
- likely missing package
- renderer unsupported command
- suspicious use of text/math mode
- possible display environment nested incorrectly
- equation numbering conflict
- macro undefined in current document context

Do not claim to prove mathematical correctness. Syntax validation is not mathematical proof.

## 8.4 Accessibility
- Keyboard-only operation.
- Screen-reader descriptions.
- MathML output where available.
- Speech text/semantic navigation where supported.
- Accessible symbol names.
- Focus management.
- High contrast and scalable UI.
- Avoid relying only on glyph appearance.
- Test with screen readers and browser accessibility tools.

## 8.5 Performance
- Debounce preview.
- Incremental updates where library permits.
- Cancel obsolete preview work.
- Limit expensive rendering of very large expressions.
- Lazy-load symbol categories.
- Cache immutable preview output by content hash.
