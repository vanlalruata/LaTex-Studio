# 3. Workspace and User Experience

## 3.1 Workspace modes
- Quick Insert dialog: compact version of the supplied screenshot.
- Full Equation Studio: advanced multi-panel workspace.
- Inline editor: small embedded mathfield for quick manuscript edits.
- Review mode: read-only formula preview with comments.

## 3.2 Full workspace layout
### Header
- Equation name.
- Save status.
- Undo/redo.
- Inline/display selector.
- Equation environment selector.
- Preview toggle.
- Export LaTeX.
- Insert into manuscript.
- More actions.

### Left panel: Symbol and Structure Library
Tabs:
- Symbols.
- Structures.
- Templates.
- Recent.
- Favorites.
- Personal library.
- Project library.

### Main panel
- Interactive mathfield.
- Raw LaTeX source editor tab.
- Optional structured expression tree.
- Selection-aware editing.

### Right panel
- Live preview.
- Structure properties.
- Equation settings.
- Template settings.
- Package requirements.
- Diagnostics.

### Bottom panel
- Validation.
- Warnings.
- Accessibility/speech representation.
- Package compatibility.
- Insertion target.

## 3.3 Layout preferences
- Split source/mathfield.
- Mathfield only.
- Source only.
- Preview focus.
- Compact symbol palette.
- Full symbol catalogue.
- Resizable panels.
- Dark/light theme.
- Compact/comfortable density.

## 3.4 Responsive behaviour
Desktop is primary for advanced composition. Tablet supports mathfield, symbol palette and preview. Mobile should provide a responsive virtual keyboard and compact category navigation. Avoid a desktop-only keyboard interaction model.
