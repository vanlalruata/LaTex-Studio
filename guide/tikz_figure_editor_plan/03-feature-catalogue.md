# 3. Feature Catalogue

## 3.1 Core drawing
- Select, multi-select, marquee select.
- Move, resize, rotate, flip.
- Duplicate, copy, paste, cut.
- Delete and lock/unlock.
- Group and ungroup.
- Bring forward/send backward.
- Layer visibility and lock.
- Align and distribute.
- Duplicate with offsets.
- Snap to grid, guides, nodes and geometry.
- Rulers and measurement guides.
- Zoom, pan, fit canvas, fit selection.
- Undo/redo and command history.

## 3.2 Object types
- Coordinates and named points.
- Rectangle, rounded rectangle, circle, ellipse.
- Polygon and regular polygon.
- Arc, sector and pie.
- Line, polyline and path.
- Bézier curves.
- Orthogonal connectors.
- Straight, curved and bent arrows.
- Double arrows and bidirectional edges.
- Braces, callouts and annotations.
- Text nodes and math nodes.
- Coordinate axes and grids.
- Matrix/table-like node layouts.
- Images and external graphics as linked assets.
- Custom node shapes where supported.

## 3.3 TikZ-specific features
- Nodes with anchors.
- Named coordinates.
- `\path`, `\draw`, `\fill`, `\filldraw`.
- Node positioning.
- Relative positioning.
- `calc` coordinate arithmetic.
- `intersection` support where parser allows.
- `fit` library.
- `matrix` library.
- `chains` library.
- `backgrounds`.
- `positioning`.
- `arrows.meta`.
- `decorations.pathmorphing`.
- `patterns`.
- `shapes.geometric`.
- `shapes.misc`.
- `shapes.symbols`.
- `shadows`.
- `quotes`.
- `angles` and `quotes` for supported angle annotations.
- Clipping and scopes in supported subset.
- Custom styles and reusable styles.
- Coordinate transformations.

## 3.4 Scientific output
- Mathematical labels.
- Greek letters and operators.
- Subscripts/superscripts.
- Fractions and matrices.
- Equation references.
- Node annotations.
- Legends and keys.
- Scale bars.
- Dimension arrows.
- Axis labels and tick marks.
- Error bars and data labels in supported chart makers.

## 3.5 Document controls
- Figure caption and label.
- Figure placement.
- Width/height.
- Scale.
- Centering.
- Float placement.
- Subfigure support through a separate composition model.
- Package requirement summary.
- Insert into current file or create standalone figure file.
