# 2. Workspace and Information Architecture

## 2.1 Main workspace

### Top toolbar
- Back to project.
- Figure name.
- Save/sync state.
- Undo/redo.
- Select, pan, zoom.
- Add node, shape, path, connector, text, math, image.
- Group/ungroup.
- Align/distribute.
- Layers.
- Grid/guides/snap.
- Preview/render.
- TikZ source.
- Export.
- Insert into manuscript.
- More actions.

### Left tool rail / library
Categories:
- Select and navigation.
- Nodes and shapes.
- Lines and arrows.
- Paths and Bézier curves.
- Text and mathematical labels.
- Decorations and annotations.
- Diagram-specific components.
- Templates and assets.

### Center canvas
- Infinite or bounded canvas.
- Zoom and pan.
- Selection handles.
- Grid and rulers.
- Alignment guides.
- Multi-select and marquee.
- Context menus.
- Object layers.

### Right properties inspector
Context-sensitive tabs:
- Geometry.
- Style.
- Text.
- Line/arrow.
- Fill/border.
- Anchors/ports.
- Transform.
- Advanced TikZ options.
- Accessibility/description.

### Bottom panel
- TikZ Source.
- Rendered Preview.
- Build Log.
- Diagnostics.
- Package Requirements.
- Export Settings.

## 2.2 Layout presets
- Visual focus.
- Code focus.
- Split canvas/code.
- Canvas/preview.
- Review mode.
- Specialized maker mode.

## 2.3 Responsive
Desktop is the primary full authoring environment. Tablet supports basic editing and preview. Mobile supports review, navigation and lightweight property changes; do not promise full precision drawing on narrow screens.

## 2.4 Interaction principles
- Context-sensitive inspector.
- Discoverable tooltips and shortcut hints.
- Non-destructive undo/redo.
- Selection and layer state clearly visible.
- Zoom-to-fit and zoom-to-selection.
- Avoid overcrowding the canvas with every possible option.
