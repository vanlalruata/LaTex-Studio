# 10 — UI/UX Screen Inventory and Design Guidance

This is a screen specification, not a final visual design. The interface should be modern, restrained, accessible, keyboard-friendly and optimized for long research sessions.

## 1. Public/authentication
- Landing page.
- Login/register/reset.
- Invitation acceptance.
- SSO login.
- Terms/privacy and service status.

## 2. Dashboard
- Recent projects.
- Create/import project.
- Templates.
- Recent builds/activity.
- Storage/build usage.
- Notifications and invitations.

## 3. Project workspace
- Left explorer/outline/search.
- Centre Monaco editor and tabs.
- Right PDF preview.
- Bottom diagnostics/build output.
- Toolbar: compile, compiler selector, root file, share, history, settings.
- Resizable/collapsible panels.
- Save and build state indicators.

## 4. Project settings
- Root file.
- Compiler and version.
- Build profile.
- Auto-compile.
- Main bibliography tool.
- Collaborators/permissions.
- Git/cloud integrations.
- Quotas and storage.

## 5. Compilation view
- Current build state.
- Compiler/version.
- Logs.
- Errors/warnings with source navigation.
- Runtime/resource metrics.
- Last successful PDF and stale status.

## 6. Bibliography
- `.bib` editor.
- Search/filter by author/title/year/DOI.
- Duplicate/missing key warnings.
- Zotero collection browser.
- Citation style preview.

## 7. Review and collaboration
- Comment sidebar.
- Inline anchored comments.
- Track-changes diff.
- Accept/reject.
- Revision timeline and compare.
- Presence indicators.

## 8. AI assistant
- Context selector.
- Chat thread.
- Compile error explanation.
- Paper review report.
- Proposed patch diff.
- Accept/reject/revert.
- AI usage and privacy disclosure.

## 9. Visual tools
- Table designer.
- TikZ figure builder.
- Probability tree.
- Sign/variation table.
- Theorem box designer.
- Source preview and copy/insert controls.

## 10. Conversion and OCR
- Source upload.
- Target format selector.
- Conversion progress.
- Conversion report.
- Preview and save as separate output.
- Formula image crop/recognition/preview/editor/insert.

## 11. Admin
- User/org/project/template search.
- Sessions and audit.
- Queue and workers.
- Image/profile management.
- Usage/quota dashboard.
- Provider configuration.
- System health and backups.

## 12. Accessibility and UX requirements
- Keyboard navigation for core actions.
- Accessible labels and focus states.
- High contrast and theme support.
- Resizable panels with persisted preferences.
- Responsive fallback.
- Clear empty/error/loading states.
- Never use color alone for status.
- Confirm destructive actions.
- Unsaved-change protection.
